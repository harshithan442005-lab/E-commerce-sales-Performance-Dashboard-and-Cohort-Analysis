E-Commerce Sales Analysis Project

Overview

This project analyzes e-commerce sales data to understand sales trends, customer behavior, and business performance.

Tools Used

- Python
- SQL
- Excel
- Power BI

Features

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- KPI dashboards
- Customer cohort analysis

How to view dashboard

Open the ".pbix" file using Power BI Desktop.

Outcome

This project helps understand sales trends and customer retention patterns.
